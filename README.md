# PDF-Viewer-with-Bun-and-Vite-using-Syncfusion-JavaScript-Components
This sample demonstrates how to run the Syncfusion JavaScript PDF Viewer in standalone mode in a Vite project, using Bun for package installation, the development server, and production builds.

## Getting Started

Follow these steps to run the application:

1. **Install dependencies**
  ```bash
  bun install
  ```

2. **Run the application**
  ```bash
  bun --bun run dev
  ```

3. **Open in browser**
  The application will typically be available at [http://localhost:5173](http://localhost:5173) or the port shown in your terminal.
